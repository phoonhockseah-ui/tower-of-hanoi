Tower of Hanoi - installable app (PWA)

1. Put every file in this folder on any HTTPS static host
   (Netlify Drop, GitHub Pages, Cloudflare Pages, Vercel).
2. Laptop (Chrome/Edge): open the site, click the install icon in the address bar.
3. Android (Chrome): open the site, menu > Install app (or Add to Home screen).
4. Optional APK: enter your site URL at pwabuilder.com and download the Android package.
